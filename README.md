🚀 CONTROLE DE IMPORTAÇÃO
O sistema de controle de importação é um sistema desenvolvido para realizar a substituição de planilhas de Excel onde se realizava o controle e 
visualização de processos de importação tais como (o numero da fatura, valores do pedido, meio de transporte e etc).

📌SOBRE O PROJETO
Este projeto foi desenvolvido com o objetivo de praticar e demonstrar conhecimentos em desenvolvimento Backend, utilizando tecnologias como Python, APIs REST e bancos de dados.

⚙️ Tecnologias utilizadas
Linguagem: Python
Framework: Django
Banco de dados: MySQL
Versionamento: Git e GitHub

✨ Funcionalidades
-Cadastro de registros
-Consulta de informações
-Atualização de dados
-Exclusão de registros
-Autenticação de usuários
-Validação de dados

💻 Como executar o projeto

1. Clone o repositório

git clone https://github.com/SEU-USUARIO/NOME-DO-PROJETO.git

2. Entre na pasta

cd NOME-DO-PROJETO

3. Crie um ambiente virtual

python3 -m venv .venv

4. Ative o ambiente virtual

Linux / macOS:

source .venv/bin/activate

Windows:

.venv\Scripts\activate

5. Instale as dependências

pip install -r requirements.txt

6. Execute a aplicação

python3 main.py
